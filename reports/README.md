# Resultados e experimentos

Salvar graficos em figures/ e tabelas agregadas em tables/. Revisar o conteudo antes de publica-lo, inclusive saidas dos notebooks, para evitar exposicao de registros individuais.

Para cada experimento, criar um arquivo Markdown com:

- Objetivo e identificador do experimento.
- Origem/versao dos dados, exercicios, semestres e filtros utilizados.
- Unidade de analise, variaveis e tratamento de dados ausentes.
- Transformacoes, algoritmo, parametros e semente aleatoria.
- Versao do codigo (commit), Python e bibliotecas.
- Metricas de avaliacao, resultados e limitacoes.
